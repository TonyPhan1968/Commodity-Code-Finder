Step 1 Construction & Fabric
Classification is determined by how the fabric is made, not the retail product name.

Jerseywear → Ch. 61 (jersey is a knitted fabric structure)
Outerwear → Ch. 61 if knitted/fleece · Ch. 62 if woven/coated
Loungewear → Ch. 61 if jersey/knit sets · Ch. 62 if woven cotton/poplin
Fleece → Ch. 61 (fleece is a raised knitted fabric)
Denim, chino, linen, poplin, twill, satin, chiffon → Ch. 62 (all woven)
Not sure? Pull a thread — if loops unravel, it's knitted (Ch. 61).
The fibre with the greatest weight determines classification. Declare exact % on C88.
